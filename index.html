How the ETL works: Extract — daily OHLCV from the Yahoo Finance chart API (no key). Transform — pandas cleaning (nulls, duplicate dates, OHLC-logic violations counted and dropped), then indicators: daily return, SMA 20/50, EMA 20, RSI 14, 20-day volatility, cumulative return. Load — SQLite stocks.db (daily_prices, ticker_summary, pipeline_runs) + JSON exports powering this page. Re-run anytime with python3 etl/pipeline.py.
